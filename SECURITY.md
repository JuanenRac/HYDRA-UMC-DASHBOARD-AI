## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

In an AI-powered dashboard, a security flaw can lead to "hallucinated" data injection or unauthorized system insights. If you discover a vulnerability affecting the **insight generation logic**, **React component XSS**, or **telemetry API authentication**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe if the bug allows injecting malicious code into the dashboard UI, bypassing data access controls, or leaking swarm efficiency reports.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy to ensure hardware safety before public release.
